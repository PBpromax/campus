## 基线准备与旧系统补齐

- [ ] B01 在当前代码基线跑通 MySQL/Redis、Spring Boot、Vue；保存启动步骤与实际结果。
- [ ] B02 统一数据库初始化与版本化迁移；修复根 SQL 与后端旧 SQL 的字段/通知表差异，验证已有数据升级。
- [ ] B03 明确 Vue 的 JS/TS 入口与配置，清理重复路径；检查开发配置、部署参数与凭证管理。
- [ ] B04 新增接单者提交完成、发布者验收、参与者取消；原子同步需求与订单状态。
- [ ] B05 接单/状态迁移加入并发条件、幂等；评价去重和信用变更保证并发一致性。
- [ ] B06 接入接单/完成/取消通知；通知 ID 和事件消费支持并发与去重。
- [ ] B07 管理员下架与关联订单协调；提供最小人工处理队列/页面。
- [ ] B08 补齐完成/取消/评价的固定页面入口；验证发布→接单→完成→评价全过程。
- [ ] B09 CI 实际执行关键业务测试；保存基础回归结果。

## M2 / W7：鸿蒙生成式交互与可信工具（15%）

- [ ] M2-01 新建 ArkTS/ArkUI Stage 客户端，接入现有鉴权和任务/订单业务。
- [ ] M2-02 类型化领域模型、状态迁移与业务不变量测试。
- [ ] M2-03 白名单组件 Renderer；校验 Schema 版本、类型、权限、Action；验证无障碍与多设备。
- [ ] M2-04 接入五类明确流式消息；支持顺序、去重、断线与恢复。
- [ ] M2-05 将现有发布/接单/查询等包装成受控工具，定义参数、权限、结果与错误契约。
- [ ] M2-06 增加结构化时间、地点、件数、报酬形式、隐私范围和合作偏好。
- [ ] M2-07 用户确认绑定具体操作与参数；修改重确认，过期/他人确认凭证拒绝执行。
- [ ] M2-08 服务端鉴权、状态校验、幂等、补偿、审计；模型与客户端不能绕过执行边界。
- [ ] M2-09 固定页面回退、取消/撤销和实际人工接管。
- [ ] M2-10 鸿蒙端现场演示“对话→卡片→修改确认→真实工具→可查业务结果”，保存测试与审计证据。

产物：鸿蒙源码/可安装构建、UI Schema 与组件白名单、协议/工具契约、后端工具/状态实现、迁移、自动化测试、M2 现场演示包。

- [ ] M3-06 LLM 部署 ADR、数据出域/最小化策略、模型路由与费用预算，保存 Token/费用测量（W11）。
