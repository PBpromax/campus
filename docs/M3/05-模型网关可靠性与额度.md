# 第三步：模型网关可靠性、额度与成本

对应课件第12—14页的Model Gateway、限额、超时、熔断、成本和降级。本轮完成本机可运行控制与故障验证；部署、系统负载/SLO评估仍留后续步骤。

## 已实现的调用边界

`本人会话 → 并发/熔断准入 → 保存用户上下文 → 出域/长度检查 → 数据库预留额度 → 单次模型请求 → 记录结果 → 建议校验/用户核对`

模型仍只能提出候选；工具执行保持独立确认。模型配额、熔断或出域检查拒绝时，完整表单、真实任务双方聊天和已确认的可信工具继续可用。

| 控制 | 当前行为 | 默认配置 |
| --- | --- | --- |
| 模型全程截止时间 | 从模型HTTP请求开始计时，覆盖连接、响应头、正文及慢速心跳；到期取消future、关闭响应流；没有自动重试 | MODEL_DEADLINE_MS=45000，允许100—50000ms |
| 响应与请求限制 | UTF-8请求负载不超过48000字节，响应输入流最多200000字节；不等到巨大一行读完才检查 | 最大输出1600 Token |
| 并发 | 单实例最多4条、每用户1条，满载立即429 | MODEL_MAX_CONCURRENT=4 |
| 熔断 | 连续3次网络/超时/供应商限流/鉴权/服务故障/协议错误后OPEN；冷却后仅1个HALF_OPEN探测；旧调用迟到成功不能关闭新熔断 | MODEL_FAILURE_THRESHOLD=3；MODEL_CIRCUIT_OPEN_MS=30000 |
| 显式停止 | 鸿蒙“停止接收”同时调用本人会话ai-cancel，取消后台请求；取消不累计供应商故障 | POST /api/need-sessions/{id}/ai-cancel |
| 日次数 | 发起前持久化预留；失败、取消、进程中断不自动退；重启不清零 | 每用户20次、全平台100次 |
| Token额度 | 每次保守预留65536输入＋1600输出；没有把字数估算当成真实Token用量 | 用户200万/日、平台1000万/日 |
| 估算费用额度 | 按峰值单价快照、输入全未命中缓存进行保守预留；与供应商实际账单分开 | 用户USD0.50/日、平台USD2.00/日 |
| 降级 | 不切换未知模型、不偷偷重发；用户可继续表单或真人协商 | 原有入口继续保留 |

默认值由本项目设定，可通过环境变量调整，不是教师指定的数值。本轮验证没有产生付费模型调用。

这里的模型截止时间不是整个HTTP业务请求的统一截止时间：数据库保存/额度预留和下游写入另有开销，SSE还有既有60秒超时。客户端关闭后若取消请求本身断网，后台最迟仍受模型截止时间约束，不能声称任意网络断开都被瞬时识别。通用长连接容量、心跳与端到端SLO仍需后续实测。

## 持久化额度的语义

新增`model_budget_days`和`model_invocations`，迁移见`database/migrations/005_model_budgets.sql`。以Asia/Shanghai自然日分桶；数据库事务内锁定当天全局行，再检查用户与全局限制、增加预留并创建RESERVED调用记录。首次建全局行的并发冲突可安全处理；没有用进程内计数冒充跨重启额度。

- 次数、Token、估算USD任一达到限制都拒绝；拒绝发生在上游请求前。
- 每次预留67136 Token，按当前报价预留USD0.02158080。保守预留不会因为已知小用量而自动缩减，因而可能提前达到限制；它不是实际收费金额。
- 发起前后有取消/进程退出等不确定窗口，预留可能没有对应成功供应商请求。没有因此自动退款或清空记录。
- 正常完成保留供应商usage和费用估算；未知用量保留NULL。失去数据库连接无法确认结算时，记录可能仍为RESERVED，保留额度并要求运维核对。
- 同一调用记录只能从RESERVED结算一次；重启不会将旧RESERVED当免费。历史M2调用没有补造费用或回填到新额度账本。
- 日额度已在同一数据库、多线程竞争中验证；限流/熔断仍是单实例，尚未做真正多节点部署验证。数据库可用性与迁移治理属于部署/SLO步骤。

`GET /api/need-sessions/ai-budget`只按JWT账号返回当天额度及最近20条本人调用记录，忽略调用者试图指定其他owner的参数。全局观测与熔断状态接口需要数据库ADMIN角色，不提供普通用户提权入口。

## 价格快照与估算

2026-10-24核对的[DeepSeek官方报价](https://api-docs.deepseek.com/quick_start/pricing/)中，deepseek-flash峰值每百万Token价格为：缓存命中输入USD0.006、未命中输入USD0.30、输出USD1.20。本实现保守使用峰值快照，不判断节假日或非峰值折扣；快照版本`deepseek-flash-20261024-peak-usd`。价格可变，部署时应重新核对和配置。

有缓存拆分时估算：

`(命中输入Token × 命中单价 + 未命中输入Token × 未命中单价 + 输出Token × 输出单价) / 1000000`

无缓存拆分但有总用量时，所有输入按未命中单价估算；没有usage则不生成“0元”记录。金额按8位小数向上取整，记录估算依据。币种固定为USD，不使用未经核对的人民币汇率。

配置入口：MODEL_USER_CALLS_PER_DAY、MODEL_GLOBAL_CALLS_PER_DAY、MODEL_USER_TOKENS_PER_DAY、MODEL_GLOBAL_TOKENS_PER_DAY、MODEL_USER_USD_PER_DAY、MODEL_GLOBAL_USD_PER_DAY、MODEL_INPUT_HIT_USD_PER_MILLION、MODEL_INPUT_MISS_USD_PER_MILLION、MODEL_OUTPUT_USD_PER_MILLION、MODEL_PRICED_MODEL、MODEL_PRICE_VERSION。模型名与价格配置不匹配时拒绝发起，避免静默套用另一模型单价。

这是本平台的保守估算额度，不是供应商账户的绝对扣款上限。供应商价格变化、异常统计、其他客户端调用和未纳入的费用仍需与真实账单核对；本轮没有发真实请求，也没有完成账单对账。

## 上下文与数据出域

Prompt版本改为campus-needs-v2，上下文版本selected-category-last20-bounded-v1：

1. 已选业务只发送该业务字段目录与当前草稿fields/contexts，不发送数据库ID、草稿版本、其他业务草稿或本地授权字段consent/deliveryConsent。未选业务仍可用四类目录辅助澄清。
2. 最多20条相关对话；超长时从最早历史开始裁减，保留系统说明与当前消息，不删除数据库历史、不截断当前需求。仍过长则拒绝发送，要求缩小范围。
3. 对疑似手机号、邮箱、Key/Bearer及带值的取件码/密码等已知模式拒绝发送；页面明确告知会发送当前业务上下文。
4. 这是有限模式检查，可能误判数学长数字，也会漏掉姓名、详细地址及其他隐私表达；不宣称完整DLP或零敏感信息出域。拒绝内容仍可存在于本人服务器会话中，不能把“未发送模型”误读为“服务器没有保存”。

真实工具继续使用完整、经用户确认的草稿。上下文裁减或模型建议不能修改资源事实、权限、信用、时限或授权。
