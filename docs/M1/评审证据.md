## 行为证据

- 统一入口提出四类候选；未知目标不会自动归OTHER，混合目标先选一项。
- 四类两两切换保留原草稿，恢复旧确认失效，不复制领域字段。
- 跑腿明确取送窗口、当面/指定点放置、通知与凭证；静默约束不能配电话。
- OTHER明确范围、资源、授权、时间和完成标准；多人先选协调/模拟拆分。
- 派生发布描述随约定更新；用户手写描述保留。
- 二十个场景分别有必要追问；借用配件/送达/归还期限按情境显示。
- 未知规格、模糊位置、非法日期、时间逆序、归还超期阻止确认。
- 送达条件明确保留“待协商”，不声称对方已承诺。
- 修改使旧确认失效；同值选择保留当前草稿；撤销后重新确认。
- 学习两步表达式与后续短消息能延续；普通对话无发布卡和报酬要求。
- 发布才出现原系统必填项；位置/时间/报酬不会自动填入，0元与原后端冲突明确显示。
- 模拟确认无真实业务ID；接管没有发给真实人员；撤销未调用真实取消接口。
- 固定表单可编辑且不绕过校验；终态可重置。
- 本页0页面异常、0业务网络请求、0localStorage/sessionStorage项；移动页无横向溢出，情境栏可横向滚动。

## 现场演示顺序

1. 说明老师项目来源、四类业务范围，以及当前有限规则/模拟边界。
2. 载入B01，未知规格不能确认；补USB-C/HDMI要求，确认本地请求草稿。
3. 改为需要送达，旧确认失效；填“附近某处”展示地点追问，再改明确位置并选待协商。
4. 将归还时间设为早于使用结束，展示冲突；撤销恢复，重新确认。展示B04配件和B05跨天期限字段。
5. 载入L05，发送“第二步 x = -2，第三步 -x = 2”，再问负号；上下文保留，无整份发布表单。
6. 主动准备发布，展示标题/描述派生来源和三项未填写的生产字段；0元不能确认，补正数后模拟发布。
7. 返回普通交流、标记解决；展示固定表单、撤销、模拟人工接管和重置。
8. 载入R05，模糊放置点不能确认；补明确位置，再改当面，原凭证要求失效，重新选当面确认。载入R02展示电话与静默冲突。
9. 载入O05补可核对完成标准；载入O02填2人，选择协调或模拟拆分，展开参数预览核对。说明现有任务单接单者边界。
10. 新会话输入“帮我代取快递”，确认分类后补字段；输入未知目标看追问与手动入口；输入“借相机＋代取快递”先选一项。
11. 在借用草稿输入跑腿目标，先选择再切换；恢复借用草稿，确认其约定保留且旧确认失效。
12. 结合业务本体解释真实任务状态与原型状态，以及M2需要落地的接口/权限。

## 可复现

```sh
cd docs/M1/prototype

npm run build
npm run preview
```

后端：Java21下执行mvn -B -Dspring.profiles.active=test test；原平台前端npm ci后npm run build。
