# M1：个性化需求、业务本体与交互原型

业务场景：**快递跑腿（EXPRESS）与学习求助（TUTORING）**。整理日期：2026-10-12。

本交付包依据[课件第7页](../AI-Native/reference/00-课程介绍.pdf)，为两个共同目标分别设计五种特殊情境。快递强调当面交付/指定点放置的交接约定；学习支持从一个小知识点或一步推导开始的碎片化沟通。快递不采用历史合作者偏好；学习不设置“隐藏薄弱点”作为第五种场景。

所有样本是 AI 辅助设计、待用户试用验证的假设。地点、时段、表达式均为演示输入，未声称来自真实访谈。原型采用 Vue + 有限规则，不调用模型、数据库或生产业务接口。

## 运行与演示

```sh
cd docs/M1/prototype
npm ci
npm test
npm run build
npm run preview
```

打开终端显示的地址（默认 <http://127.0.0.1:5181>）。已有 `release/` 构建可用静态服务器运行；不能直接双击 HTML，因为浏览器可能拦截本地模块文件。详细说明见原型 README。

## 完成边界

本包已提供需求、本体、交互设计和规则原型，测试结果以 06 和 evidence 中的实际记录为准。真实用户试用仍待开展；真实模型、鸿蒙客户端、可信工具执行和生产人工接管属于后续 M2 工作。浏览器测试不能替代真人试用，也不能证明真实模型理解能力。
