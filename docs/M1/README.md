## 运行与现场展示

```sh
cd docs/M1/prototype
npm ci
npm test
npm run build
npm run preview
```

打开 http://127.0.0.1:5187 。源码、锁文件、规则测试和release构建均随交付保存。详细演示及证据见评审证据。

统一入口：表达目标→候选分类→用户选择；混合或未知目标先澄清。业务切换保留原草稿，恢复后重新确认。

跑腿：取送物品→时间窗口→当面/放置约定→确认；其他：协助目标→资源与授权→时间地点→完成标准→确认。多人协助明确单人协调或模拟拆分，不能宣称现有系统支持多人接单。

借用：用途/规格→借期和取还→约定卡→修改→重新模拟确认。学习：小问题→补表达式→继续追问；准备发布时才出现发布确认卡和原系统必填项。

## 能力与完成边界

有限规则模拟，无真实模型、库存、匹配、支付、发布或人工队列。原型状态与后端任务状态分开；普通学习消息不变成订单。声明式JSON契约尚未实现鸿蒙Renderer。M2接真实系统前须重新落实生产字段、角色授权、状态、幂等和审计。

原平台保留RUNNING/STUDY/BORROW/OTHER，本阶段深入四类；扩展范围来自用户的完整业务目标，不声称老师规定必须四类。现有API和业务表未新增；迁移只整理配置、初始化开关、SQL数据和交付结构。
